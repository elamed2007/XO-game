# XO Game

A classic Tic-Tac-Toe (XO) game built with HTML, CSS and JavaScript. Two players enter their names, choose who plays first, then take turns placing X and O on the board. Responsive layout for desktop, tablet and phone.

## Live Demo

Play it online: https://elamed2007.github.io/XO-game/

## Features

- Player name input with validation
- Turn indicator and winner / draw detection
- Replay and Exit buttons
- Responsive design for desktop, tablet and phone
- XSS protection on player names

## How to run locally

Open `index.html` in any web browser.
